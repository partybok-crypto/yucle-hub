# 유클 업무 허브 (링크허브)

폰·PC에서 쓰는 프로그램 바로가기, 데이터 흐름, 화면 캡처, 연결 지도, **팀 운영 신호등**을 한 페이지에 모은 허브.

- 공개 주소: https://partybok-crypto.github.io/yucle-hub/
- 저장소: `partybok-crypto/yucle-hub` (main 푸시 → 1~2분 뒤 반영)
- `index.html`·`sw.js`는 생성물. 직접 고치지 말고 `tools/`를 고친 뒤 `python tools/build.py`

## 화면 구성
| 탭 | 내용 |
|---|---|
| 바로가기 | 프로그램 카드(테마1/2, PC·모바일 캡처), 상단 안내줄(서버 이상·내부 오류) |
| 사이트 | 프로그램이 쓰는 외부 사이트 |
| 연결 지도 → **팀 운영** | 마케팅·영업·운영·CS 4개 팀 신호등. "회사의 속도 = 가장 좁은 곳의 속도", 가장 나쁜 팀으로 들어가는 관이 빨간 "병목" |
| 연결 지도 → 연결 한눈에 | 프로그램 사이 데이터 연결을 점이 흐르는 관으로 표시. 막힘=빨강, 느림·내부 오류=노랑. 마케팅OS 모듈별 상태 포함 |
| 연결 지도 → 프로그램별 카드 | 입력/저장/외부연동/자동실행/연결 상세 |
| 구조도 | Archify 구조도(HTML) |

"움직임: 켬/끔" 버튼으로 흐르는 점 애니메이션을 끌 수 있다(기기마다 기억).

## 팀 운영 지표 (2026-11-25 추가)
측정 → 기준 → 개선을 반복하기 위한 화면. 3시간마다 `monitor.py`가 `kpi.py`를 불러 각 프로그램의 공개 조회 API에서 **개수만** 모아 `status.json`의 `kpi`에 넣는다.

| 팀 | 지표 | 출처 | 기준 |
|---|---|---|---|
| 📣 마케팅 | 오늘 미복구 오류, 이상 있는 모듈, 오늘 자동 작업 정상 비율 | 마케팅OS `/api/today-glance`·`/api/modules`·`/api/errors` | 오류 1건↑ 주의·20건↑ 위험 / 모듈 1개↑·3개↑ / 80%·50% 미만 |
| 📞 영업 | 오늘 AI 발신, 오늘 관심 고객, 이번 달 통화 분 사용 | AI 전화상담 `/api/model2/today`·`/api/bulk/usage` | 발신·관심고객은 **기준 정립 중** / 사용량 80%·95% |
| 🏭 운영 | 현장 이상 징후, 포장 진행률, 출근 인원, 건조기 가동 | 공장 전광판 `/api/issues`·`/api/display/packing-plan`·`/api/status` | 포장·인원은 **세탁공장 일정표 대비**(아래) |
| 💬 CS | 미처리 부재중, 미해결 클레임(14일), 시트 동기화 문제 | 회사전화 `/api/live`·`/health`, 전광판 `/api/display/claims` | 1건↑ 주의 / 부재중 10건·클레임 5건↑ 위험 |

- 기준표: `tools/kpi.json` (`dir`=low/high, `warn`/`bad`, `null`이면 기준 없음, `note`=메모, `sched`=일정표 대비, `auto`=같은 요일·시각 평균 대비)
- **일정표 기준**: "세탁공장-일정표" 구글시트의 `주차별 쉬프트` 탭 오른쪽(이번 주 일정표·시간별 인원)을 서비스 계정으로 읽음(이름은 읽지 않음)
  - 포장 진행률: 오늘 첫 출근 ~ 같은 요일 지난 3주 평균 세탁 마감까지 고르게 진행한다고 본 예상 진행률 대비. 예상의 85% 밑 주의, 70% 밑 위험
  - 출근 인원: 지금 시각 계획 인원 대비. 모자라면 주의, 2/3 밑 위험
  - 일정표에 오늘 날짜가 없으면 같은 요일·시각 평균(기록 3회 이상)으로 대체
- 날짜별 기록: `tools/kpi_hist.json`(로컬 전용, 30일, 요일·시각 슬롯 포함). 2일 이상 쌓이면 지표 옆에 추세선
- `status.json`은 공개 저장소에 올라가므로 이름·전화번호·금액·거래처는 넣지 않는다

## 주요 파일
| 파일 | 역할 |
|---|---|
| `tools/links.json` | 프로그램 목록·주소·하위 메뉴 |
| `tools/flow_part1~3.js`, `tools/short.js` | 데이터 흐름 상세·짧은 칩 |
| `tools/map.json`, `tools/sites.json` | 연결 지도(그룹·연결·레인), 사이트 목록 |
| `tools/kpi.json`, `tools/kpi.py` | 팀 운영 기준표, 지표 수집 |
| `tools/template.html` | 화면 코드 |
| `tools/build.py` | 위 파일 → `index.html`, `sw.js` |
| `tools/monitor.py` | 3시간마다 서버 점검 + 팀 지표 수집 → `status.json` → 푸시, 이상 시 메일 |
| `tools/refresh.py` | 캡처 + 빌드 + 커밋 + 푸시 |
| `tools/capture.py`, `tools/capture_m.py` | PC·모바일 캡처(개인정보 흐림) |
| `tools/notify.py` | 메일 발송 |

자세한 작업 규칙은 `CLAUDE.md`, 남은 일은 `TASKS.md`.
